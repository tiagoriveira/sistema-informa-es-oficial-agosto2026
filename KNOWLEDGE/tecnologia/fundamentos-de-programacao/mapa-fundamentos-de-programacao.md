# Mapa — Fundamentos de Programação

**Fontes desta disciplina:** nenhuma em `RAW/` — grade checada por busca na web em 2026-08-17
(ver "Nota sobre a grade").
**Estado do aluno:** [[estado-fundamentos-de-programacao]]

**Pré-requisito do hub.** As outras três disciplinas de `tecnologia` assumem que estes
fundamentos já foram cobertos — é a base de [[mapa-engenharia-de-software]] e
[[mapa-dados-estatistica-e-ia-ml]].

## Ordem de estudo sugerida
_(status derivado do LEARNER — não editar à mão, regenerado a cada UPDATE. `CLAUDE.md` §4.2:
esta ordem não é dogma, desvie quando houver motivo)_

### Fase 1 — Pensamento computacional e lógica
1. ⬜ O que é um programa — como o computador executa instrução
2. ⬜ Variáveis, tipos de dado e operadores
3. ⬜ Estruturas condicionais — decisão no código
4. ⬜ Loops e repetição — fazer o computador repetir por você
5. ⬜ Funções — dividir problema em partes reutilizáveis

### Fase 2 — Estruturas de dados e manipulação
6. ⬜ Listas/arrays — organizar coleção ordenada
7. ⬜ Dicionários/mapas — busca por chave
8. ⬜ Strings e manipulação de texto
9. ⬜ Tratamento de erros e exceções
10. ⬜ Recursão — função chamando a si mesma

### Fase 3 — Orientação a objetos
11. ⬜ Classes e objetos — modelar o mundo em código
12. ⬜ Encapsulamento — esconder complexidade
13. ⬜ Herança e polimorfismo — reuso e especialização
14. ⬜ Composição vs. herança — quando preferir cada um

### Fase 4 — Algoritmos e complexidade
15. ⬜ Big O — medir eficiência de um algoritmo
16. ⬜ Busca e ordenação — os algoritmos clássicos
17. ⬜ Pilha e fila
18. ⬜ Árvore e grafo — estrutura hierárquica e de rede
19. ⬜ Hash table — por que buscar em O(1)

### Fase 5 — Prática de engenharia básica
20. ⬜ Controle de versão com Git
21. ⬜ Debugging sistemático
22. ⬜ Testes automatizados
23. ⬜ Ler documentação e código de terceiros
24. ⬜ Ambiente de desenvolvimento — dependência, ambiente virtual, pacote

## Nota sobre a grade
Grade desenhada em 2026-08-17 a partir de busca na web (regra `CLAUDE.md` §6). Sem linguagem
específica pedida pelo Tiago — a sequência é agnóstica de linguagem, mas roteiros atuais
