# Frameworks de copy: qual usar, e quando nenhum serve

**Ideia central:** framework é **andaime, não prédio** — serve para não travar e não esquecer
parte; copy boa não parece framework, e no mercado saturado o andaime atrapalha.

## Os principais
- **AIDA** (atenção, interesse, desejo, ação) — o mais antigo e genérico. Bom para peça curta.
  Fraco em mercado sofisticado porque não tem espaço explícito para mecanismo e prova.
- **PAS** (problema, agitação, solução) — o mais eficiente para tráfego frio e consciência
  nível 2, porque começa onde a pessoa já está. Risco: agitação excessiva vira manipulação.
- **BAB** (antes, depois, ponte) — bom quando a transformação é visível: obra, estética,
  performance.
- **4 Ps** (promessa, panorama, prova, empurrão) — mais completo, bom para peça longa.
- **StoryBrand** (Donald Miller) — o cliente é o herói, a marca é o guia. Útil para organizar
  mensagem institucional e site; menos para resposta direta pura.

## Como escolher
| Situação | Framework |
|---|---|
| Tráfego frio, dor clara | PAS |
| Transformação visível | BAB |
| Página de venda longa | 4 Ps |
| Site institucional e posicionamento | StoryBrand |
| Mercado no estágio 3 ou acima | **nenhum** — estruture em torno do mecanismo |

> Esta tabela é recomendação prática, **não resultado de comparação testada**. Nenhum framework
> tem evidência comparativa publicada de superioridade; quem afirma que um converte mais está
> generalizando experiência própria.

## Erros comuns
- Preencher o framework como formulário e entregar texto mecânico.
- Usar AIDA num mercado que já ouviu tudo.
- Trocar de framework quando o problema é a oferta.
