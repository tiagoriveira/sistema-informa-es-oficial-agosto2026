# CODE — Capture, Organize, Distill, Express

**Ideia central:** ciclo de quatro etapas que força a informação a se mover em vez de
empilhar — é a resposta direta ao [[arquivo-morto]].

## Explicação
De Tiago Forte ("Building a Second Brain"):

- **Capture** — guardar só o que ressoa (te fez pensar diferente, é raro, é reusável). Se não
  te surpreendeu e você não vai reusar, não capture. Ver [[captura-seletiva]].
- **Organize** — não por assunto, por **ação**: onde essa informação vai ser usada?
- **Distill** — resumir progressivamente: negrito no que importa, depois destaque só o
  essencial do negrito, até sobrar a essência.
- **Express** — produzir algo com a nota. Nota que nunca vira output é nota morta — a mesma
  falha do arquivo morto, só que mais tarde no processo.

O valor não está em nenhuma etapa isolada: está no fato de cada uma **obrigar a informação a
mudar de forma**. Informação que não muda de forma é informação que não foi processada.
