# Comandos e hotkeys do Obsidian

> **Página inteiramente de conhecimento externo.** Nada aqui vem de fonte em `RAW/` — a
> origem é a documentação oficial do Obsidian, consultada em **2026-08-15**. Atalho padrão
> muda entre versões: se divergir do seu app, **o app está certo e esta página está velha**.
> A verdade viva está em Settings → Hotkeys.

**Ideia central:** a paleta de comandos (`Ctrl+P`) é a porta única para tudo que o Obsidian
faz — atalho dedicado é otimização, e só compensa no que você roda todo dia.

## Por que a paleta vem antes da lista

A paleta mostra **o atalho de cada comando ao lado do nome**. Ela é catálogo e executor ao
mesmo tempo: você descobre comandos usando, não decorando. Isso inverte a ordem de
aprendizado — não se estuda a lista de atalhos, se estuda a paleta, e os atalhos grudam nos
comandos que você repete.

Regra prática: **tecla dedicada só pro diário; o resto, paleta.** Atalho ligado a comando de
uso mensal ocupa espaço de memória e colide com o que importa.

Comandos usados muito no celular podem ser **fixados** (pinned) para aparecer no topo da
paleta — Settings → Core plugins → Command palette.

## Padrão no Windows

Navegação:

| Tecla | Faz |
|---|---|
| `Ctrl+P` | paleta de comandos |
| `Ctrl+O` | quick switcher — abre nota digitando o nome |
| `Ctrl+Shift+F` | busca no vault inteiro |
| `Ctrl+F` | busca na nota atual |
| `Ctrl+G` | grafo |
| `Ctrl+,` | configurações |

Escrita e edição:

| Tecla | Faz |
|---|---|
| `Ctrl+N` | nota nova |
| `Ctrl+E` | alterna edição / leitura |
| `Ctrl+B` `Ctrl+I` `Ctrl+K` | negrito, itálico, link externo |
| `Ctrl+Shift+V` | colar **sem** formatação |
| `Ctrl+Shift+K` | apaga a linha inteira |
| `Ctrl+Backspace` / `Ctrl+Delete` | apaga a palavra anterior / seguinte |
| `Ctrl+Home` / `Ctrl+End` | início / fim da nota |
| `Ctrl+Shift+Home` / `Ctrl+Shift+End` | seleciona até o início / fim da nota |

O wikilink **não tem atalho**: digitar `[[` abre o autocomplete. É gesto de digitação, não
comando — por isso não aparece na paleta.

## Comandos que valem ligar (sem tecla padrão confiável)

Procure pelo nome em Settings → Hotkeys. Não listo tecla porque varia entre versões e
instalações:

- *Open today's daily note* — captura sem decidir onde salvar
- *Insert template* — ver [[mapa-obsidian]], tópico 16
- *Split right* — duas notas lado a lado
- *Follow link under cursor* — navegar sem tirar a mão do teclado
- *Rename file* · *Move file to another folder*
- *Add alias* — ver tópico 11 da grade

## Erros comuns

- **Decorar a lista antes de usar a paleta.** A lista sem uso não gruda; a paleta ensina no
  fluxo de trabalho.
- **Ligar atalho demais.** Colisão silenciosa: o Obsidian aceita o conflito e um dos dois
  para de responder.
- **Tratar esta página como autoridade.** Ela é cópia datada de doc externa — em conflito,
  o app vence.
