# Jobs to Be Done (JTBD)

**Ideia central:** pessoas não compram produtos — "contratam" algo para realizar um "job"
(tarefa/objetivo) em um contexto específico.

## Explicação
A pergunta central não é "quem é o cliente" (perfil demográfico), é "que job ele está tentando
resolver, e o que ele contrata hoje para isso". Isso muda a pesquisa: em vez de perguntar sobre
a solução hipotética, pergunta-se sobre o comportamento passado — o que a pessoa já contratou
pra resolver aquele job.

Consequência prática: o "concorrente" real nem sempre parece com o seu produto. É quem já é
contratado para o mesmo job.

## Exemplo
O job do produtor rural não é "usar um app de pagamento" — é algo como "manter as finanças
organizadas sem precisar entender de finanças e sem perder tempo". Hoje, quem ele contrata
para esse job é o contador. Nessa lente, o contador é concorrente por resolver o mesmo job, não
por parecer com o produto.
