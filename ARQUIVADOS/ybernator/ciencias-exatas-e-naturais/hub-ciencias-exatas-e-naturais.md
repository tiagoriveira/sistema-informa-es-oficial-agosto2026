# Ciências Exatas e Naturais

Hub criado em 2026-08-18 na importação do Ybernator. 5 disciplinas, 95 tópicos.

Sequência recomendada: a matemática é a linguagem das outras; estatística é a ponte para o
hub de tecnologia.

1. [[mapa-matematica]] — a linguagem que as outras disciplinas usam.
2. [[mapa-fisica]] — as leis do mundo material, escritas em matemática.
3. [[mapa-quimica]] — o que a matéria é e como reage.
4. [[mapa-biologia]] — o vivo, que é química organizada.
5. [[mapa-estatistica]] — inferir a partir de dado incompleto. Porta de entrada para
   [[mapa-dados-estatistica-e-ia-ml]] (hub tecnologia).

**Fronteira com [[mapa-dados-estatistica-e-ia-ml]]:** aqui é estatística como ciência
(distribuição, inferência, teste); lá é estatística aplicada a machine learning e modelo
preditivo.

**Fronteira com [[mapa-neurociencia-geral]]** (hub neurociência): biologia aqui é geral
(célula, evolução, sistemas); lá é sistema nervoso especificamente.

**Aviso:** grades importadas do Ybernator sem checagem web. Estas são das áreas mais estáveis
do vault — conteúdo de ciência básica não envelhece em anos, diferente de tecnologia.
