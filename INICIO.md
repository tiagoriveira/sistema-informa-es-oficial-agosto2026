## Como usar (referência rápida)

| Você diz | A IA faz |
|---|---|
| "ingere a fonte X" | lê a fonte, extrai conceitos, cria/atualiza páginas |
| "quero estudar X" / "continue" | explica direto (fricção zero); avalia só quando pedido, revisão vencida, ou modo ativo sinalizado |
| "o que eu tenho para revisar?" | lista as revisões vencidas |
| "fecha a sessão" | grava sessão, recalcula revisões, atualiza este arquivo, commit + push |
| "roda um lint" | audita o vault e reporta problemas |
| "o que eu já sei sobre X?" | responde a partir do vault, com citação |
